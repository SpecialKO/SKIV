1.0.0
=====
 + Added an HDR-to-SDR tone mapper setting, in Settings and in the context
     menu of HDR images. It is used to show HDR images on SDR displays, and
     when saving or copying HDR images and screen captures as SDR.
    * Default:        The image's range mapped to that of SDR (as before).
    * SKIV Piecewise: Keeps the darker half of SDR as is, and compresses
                      the highlights.
    * SKIV Auto Tone: Like Piecewise, but darkens the midtones of bright
                      scenes to make room for the highlights.
 + Added playback of animated images: APNG, GIF, WebP and AVIF.
 + Added color management: ICC profiles and wide gamut images are now
     shown with the right colors, and HLG images are supported.
 + Added a thumbnails carousel along the bottom of the viewer, and faster
     browsing through folders.
    * Added Home/End navigation, and a setting to loop through the images
        of a folder.
 + Added zooming, dragging and double-clicking of the image in the viewer,
     and an Automatic mode to the Scaling menu.
 + Added a native (Windows) context menu, sorting as File Explorer does,
     and deleting the image shown.
 + Region captures now work across all displays, and while SKIV is
     minimized.
    * Selections can be dragged in any direction, and a right click
        cancels them.
    * The snipping toolbar can save to disk and pick the file to save to.
 + Added a Screenshots folder with a configurable naming scheme for saved
     screen captures, including the window's title and process name.
 + Added a Discord Compatibility option, so that Discord shows thumbnails
     of HDR PNGs in HDR.
 + Improved copying and pasting, including pasting images from browsers.
 + Added SDR AVIF decoding and encoding.
 + Improved support for Photoshop documents (.psd).
 + Large progressive JPEGs load faster, with a preview while they load.
 + The image details show DDS texture information.
 + Keybindings:
    * Hotkeys can be turned off without unbinding them.
    * Enter (or Numpad Enter) confirms a new keybinding.
    * Escape, Backspace, Delete and Enter can be bound with a modifier held
        (e.g. Ctrl+Delete).
    * Viewer hotkeys are disabled while on the Settings tab.
 + Added support for Windows 7 and 8, and 32-bit builds are back.
 + OpenEXR (.exr) images are not supported in this build.
 + Fixed crashes when navigating past the final image, when deleting files
     from elsewhere, and when using too long paths.
 + Fixed memory leaks when browsing images.
 + Fixed HDR detection on multi-monitor setups.
 + Fixed screenshot paths with some regional date formats.
 + Fixed Escape not minimizing the app again from the system tray.
 + Fixed deleting the only image of a folder.
 + Fixed the snipping toolbar not accepting clicks.
